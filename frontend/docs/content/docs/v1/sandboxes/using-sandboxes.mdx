- `read` and `write` carry up to 2 MiB per file. A larger file fails with code `too_large`. One workaround is to fetch it inside the sandbox and operate on it.

## Finding and cleaning up

`hatchet.sandbox.list({ metadata })` returns the sandboxes whose tags include every pair you pass. `hatchet.sandbox.delete({ metadata })` deletes every match with all of its snapshots, and returns their IDs. Both filters are subset matches, so `{ conversation: "42" }` matches a sandbox tagged `{ conversation: "42", user: "ada" }`.

`kill()` stops the machine and keeps the snapshots, so `connect` still works and the provider stops billing you for a running machine. `delete()` removes the sandbox and its snapshots from the provider.

<Callout type="info">
  Idle sandboxes stop on their own after the provider's max idle time, 3600
  seconds by default. Stopped sandboxes still hold their snapshots at the
  provider until you delete them.
</Callout>
