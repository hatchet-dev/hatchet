# TypeScript SDK

This is the generated API reference for the Hatchet TypeScript SDK. For concepts and guides, see the [user guide](/v1).

## Core pages

- [Client](/reference/typescript/client): The main Hatchet client, its configuration, and the feature client accessors
- [Context](/reference/typescript/context): The context object passed to tasks at runtime
- [Embedded](/reference/typescript/embedded): Run a full Hatchet engine in-process for local development
- [Runnables](/reference/typescript/runnables): Tasks and workflows, the objects you register on workers and run
