# Pydantic Support

The V1 Hatchet SDK leans heavily on [Pydantic](https://docs.pydantic.dev/latest/) (both internally and externally) for handling validation of workflow inputs and outputs, method inputs, and more.

### Usage

To enable Pydantic for validation, you'll need to:

1. Provide an `input_validator` as a parameter to your `workflow`.
2. Add return type hints for your `tasks`.

### Default Behavior

By default, if no `input_validator` is provided, the task receives `None` as its input. For example:

<Snippet src={snippets.python.simple.worker.simple} />

In this simple example, the task's `input` argument is typed as `None`, since the workflow declares no input model. Provide an `input_validator` to receive a validated Pydantic model instead.
