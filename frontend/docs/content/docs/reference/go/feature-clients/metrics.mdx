# Metrics Client

Accessed via `client.Metrics()` on the [Hatchet client](../client).

## MetricsClient

MetricsClient provides methods for retrieving metrics for workflows, tasks, and tenant queue

Methods:

| Name                  | Description                                                       |
| --------------------- | ----------------------------------------------------------------- |
| `GetQueueMetrics`     | GetQueueMetrics retrieves tenant-wide queue metrics.              |
| `GetTaskQueueMetrics` | GetTaskQueueMetrics retrieves tenant-wide step run queue metrics. |
| `GetWorkflowMetrics`  | GetWorkflowMetrics retrieves metrics for a specific workflow.     |

### Functions

#### `GetQueueMetrics`

GetQueueMetrics retrieves tenant-wide queue metrics.

```go
func (m *MetricsClient) GetQueueMetrics(ctx context.Context, opts *rest.TenantGetQueueMetricsParams) (*rest.TenantQueueMetrics, error)
```

Parameters:

| Name   | Type                                |
| ------ | ----------------------------------- |
| `ctx`  | `context.Context`                   |
| `opts` | `*rest.TenantGetQueueMetricsParams` |

Returns:

| Type                       |
| -------------------------- |
| `*rest.TenantQueueMetrics` |
| `error`                    |
