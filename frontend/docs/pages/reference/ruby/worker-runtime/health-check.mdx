# Class Hatchet::WorkerRuntime::HealthCheck

**Inherits:** `Object`

Simple HTTP health check server using raw TCPServer.

WEBrick was removed from Ruby's default gems in Ruby 3.4+, so we use a raw
TCPServer with minimal HTTP response to avoid adding a dependency.

**Example**

```ruby
health = HealthCheck.new(port: 8001, logger: logger)
health.start  # runs in a background thread
health.stop
```
