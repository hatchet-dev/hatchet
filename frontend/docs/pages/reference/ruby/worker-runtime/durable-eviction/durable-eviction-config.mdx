# Class Hatchet::WorkerRuntime::DurableEviction::DurableEvictionConfig

**Inherits:** `Object`

Configuration for the background eviction loop.

## Attributes

## `check_interval`

_Read-only attribute_

- **Returns** [Float] Seconds between eviction checks.

## `min_wait_for_capacity_eviction`

_Read-only attribute_

- **Returns** [Float] Minimum seconds a run must have been waiting before it
  becomes eligible for capacity-based eviction.

## `reserve_slots`

_Read-only attribute_

- **Returns** [Integer] Slots to reserve from capacity-eviction decisions.
