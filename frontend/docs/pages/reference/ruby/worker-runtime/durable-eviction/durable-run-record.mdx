# Class Hatchet::WorkerRuntime::DurableEviction::DurableRunRecord

**Inherits:** `Object`

Per-run state tracked by the cache.

`wait_count` is ref-counted so concurrent waits over the same durable run
don't prematurely clear the waiting flag when one child completes before the
others.
