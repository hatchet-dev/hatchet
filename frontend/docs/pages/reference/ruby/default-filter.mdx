# Class Hatchet::DefaultFilter

**Inherits:** `Object`

Defines a default filter for event-triggered workflows

**Example: Filter with scope and payload**

```ruby
Hatchet::DefaultFilter.new(
  expression: "true",
  scope: "example-scope",
  payload: { "main_character" => "Anna" }
)
```

## Attributes

## `expression`

_Read-only attribute_

- **Returns** [String] CEL expression to evaluate

## `payload`

_Read-only attribute_

- **Returns** [Hash] Static payload for the filter

## `scope`

_Read-only attribute_

- **Returns** [String, nil] Scope for filter matching
