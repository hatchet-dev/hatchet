# Class Hatchet::TaskRunRef

**Inherits:** `Object`

Reference to a running standalone task, returned by `Task#run_no_wait`.

Wraps a `WorkflowRunRef` and automatically extracts the task-specific output
from the workflow-level result. For a task named "my_task", calling `result`
returns the task output directly (e.g. `{"value" => 42}`) instead of the full
keyed output (`{"my_task" => {"value" => 42}}`).

**Example**

```ruby
ref = my_task.run_no_wait(input)
output = ref.result  # => {"value" => 42}
```

- **Raises** [Hatchet::FailedRunError] if the workflow run failed
