# Module Hatchet::Connection

Connection management for gRPC channels.

Creates a shared gRPC channel with proper TLS/mTLS configuration and keepalive
settings. The channel is shared across all gRPC stubs (dispatcher, admin,
events) for connection reuse and thread safety.
