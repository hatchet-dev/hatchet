# Class Hatchet::Features::Scheduled

**Inherits:** `Object`

Scheduled client for managing scheduled workflows within Hatchet

This class provides a high-level interface for creating, deleting, updating,
bulk operations, listing, and retrieving scheduled workflow runs.

- **Since** 0.1.0

**Example: Creating a scheduled workflow**

```ruby
scheduled = scheduled_client.create(
  workflow_name: "my-workflow",
  trigger_at: Time.now + 3600,
  input: { key: "value" },
  additional_metadata: { source: "api" }
)
```

## `create`

`create(workflow_name:, trigger_at:, input: = {}, additional_metadata: = {})`

Create a new scheduled workflow run

IMPORTANT: It's preferable to use Workflow.run to trigger workflows if
possible. This method is intended to be an escape hatch.

**Parameters:**

| Name                  | Type     | Description                                                      |
| --------------------- | -------- | ---------------------------------------------------------------- |
| `workflow_name`       | `String` | The name of the workflow to schedule (namespace will be applied) |
| `trigger_at`          | `Time`   | The datetime when the run should be triggered                    |
| `input`               | `Hash`   | The input data for the scheduled workflow                        |
| `additional_metadata` | `Hash`   | Additional metadata associated with the future run               |

- **Raises** [HatchetSdkRest::ApiError] If the API request fails
- **Returns** [Object] The created scheduled workflow instance
- **Since** 0.1.0

**Example**

```ruby
scheduled = scheduled_client.create(
  workflow_name: "my-workflow",
  trigger_at: Time.now + 3600,
  input: { key: "value" },
  additional_metadata: { source: "api" }
)
```

## `update`

| -------------- | -------- | -------------------------------------------------- |
| `scheduled_id` | `String` | The ID of the scheduled workflow run to reschedule |

- **Returns** [Object] The updated scheduled workflow instance
- **Since** 0.1.0

**Example**
