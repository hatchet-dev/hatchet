# Class Hatchet::Task

**Inherits:** `Object`

Represents a task within a workflow (or a standalone task).

Tasks are the basic unit of work in Hatchet. They can be defined as part of a
workflow or as standalone tasks. Each task has a block that executes the task
logic, receiving the workflow input and a context object.

**Example: Task defined in a workflow**

```ruby
step1 = workflow.task(:step1) { |input, ctx| { "result" => "done" } }
```

**Example: Standalone task**

```ruby
task = hatchet.task(name: "my_task") { |input, ctx| { "result" => "done" } }
```

## `run`

`run(input = {}, options: = nil)`

Run this task (or its owning workflow) synchronously.

For standalone tasks the result is automatically unwrapped so that the caller
receives the task output directly (e.g. `{"result" => "done"}`) rather than
the workflow-level output keyed by task name (e.g. `\{"my_task" => \{"result" =>
"done"\}\}`).

**Parameters:**

| Name      | Type                          | Description     |
| --------- | ----------------------------- | --------------- |
| `input`   | `Hash`                        | Input data      |
| `options` | `TriggerWorkflowOptions, nil` | Trigger options |

- **Raises** [Error]
- **Returns** [Hash] The task output
