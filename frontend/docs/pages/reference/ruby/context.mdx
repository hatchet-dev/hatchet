# Class Hatchet::Context

**Inherits:** `Object`

Context object passed to task execution blocks.

Provides access to workflow run metadata, parent task outputs, logging,
cancellation, and other runtime capabilities.

**Example: Accessing parent output**

```ruby
workflow.task(:step2, parents: [step1]) do |input, ctx|
  parent_result = ctx.task_output(step1)
  { "sum" => parent_result["value"] + 1 }
end
```

_Read-only attribute_

- **Returns** [Hash] Additional metadata attached to this run

## `attempt_number`

_Read-only attribute_

_Read-write attribute_

_Read-only attribute_

## `priority`

_Read-only attribute_

- **Returns** [Integer, nil] Task priority

## `retry_count`

_Read-only attribute_

- **Returns** [Integer] Current retry count (0 on first attempt)

## `step_run_id`

_Read-only attribute_

## `worker_id`

_Read-only attribute_

## `workflow_run_id`

_Read-only attribute_

- **Returns** [String] The workflow run ID

## Public Instance Methods

## `cancel`

`cancel()`

Cancel the current workflow run.

Batch tasks share one context across every buffered member, so there is no
single task run to cancel; instead this sends a batch CANCELLED event covering
every member of the batch.

## `cancelled?`

`cancelled?()`

Check if the task has been cancelled

- **Returns** [Boolean] true if cancellation has been requested

## `get_task_run_error`

`get_task_run_error(task_ref)`

Get the error from a specific upstream task (used in on_failure tasks)

**Parameters:**

| Name       | Type                   | Description                  |
| ---------- | ---------------------- | ---------------------------- |
| `task_ref` | `Task, Symbol, String` | Reference to the failed task |

- **Returns** [TaskRunError, nil] The task run error, or nil

## `log`

`log(message)`

Log a message via the Hatchet logging system. Sends the log to the server via
gRPC if an event client is available.

**Parameters:**

| Name      | Type           | Description        |
| --------- | -------------- | ------------------ |
| `message` | `String, Hash` | The message to log |

`refresh_timeout(duration)`

`release_slot()`

a resource-intensive phase followed by a lighter phase.
