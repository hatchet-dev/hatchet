# Class Hatchet::OrCondition

**Inherits:** `Object`

Represents an OR group of conditions. The task proceeds when ANY condition is
met.

**Example: Wait for either a sleep or event**

```ruby
Hatchet.or_(
  Hatchet::SleepCondition.new(60),
  Hatchet::UserEventCondition.new(event_key: "start")
)
```
